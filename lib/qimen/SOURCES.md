# 奇门引擎规则、来源与许可

本目录提供 `/qimen` 的确定性计算、档案和导出。计算在浏览器本地执行，不需要 API。

## 本版口径

`chaibu-kun2-zi23-v1`：时家转盘、拆补、甲己符头定元，固定 UTC+08:00；23 点换日。立春年柱、节令月柱和阴阳遁定局使用实际交节时刻，不提前到当日零点。中五固定寄坤二，天禽随天芮；值使从旬首六仪的**原宫（包含五宫）**按阳顺阴逆数时，最后落五宫才寄二宫。八神统一采用白虎、玄武，不随阳遁改称勾陈、朱雀。

农历日期表示钟表日期，23 点时日柱及符头已进入次日；此差异会明确写在页面及导出中。时旬空、时驿马随时柱计算。只接收公历 1900–2100 年；未宣称超出此范围的准确度，也不承接其他功能的年份验证范围。

## 复核边界

截图样例与边界测试验证的是上述规则及输出一致性，不代表所有奇门流派都应生成相同结果。暂不提供置闰、茅山、真太阳时、暗干、长生旺衰和吉凶格局切换，避免用未核验规则填充盘面。

复制和 Markdown 导出使用同一个当前盘对象；PNG 捕获同一盘面快照。档案存完整盘及规则版本，恢复旧版本不会静默重算。盘库只在当前浏览器，跨设备请导出文件。
