# 与 Metis 排盘规则的逐层对照

日期：2026-10-17。对象：当前工作区与 Metis 公开仓库、官网当前部署的排盘代码。所有出生资料均为合成测试样本。结论适用于网页当前默认的 split 闰月口径；不等同于所有流派、所有商业功能或预测准确率已经验证。

## 结论

**相同的规范化出生日期和时辰下，本命核心一致；默认大限、流年、流月、流日、流时的主计算一致。输入边界和显示范围存在明确差异，因此不能宣称完整复刻、所有钟表输入或所有界面完全相同。**

本轮修复三个已复现问题：节气四柱丢失分钟、AI 重建丢失标准时刻、同农历年尚未到达出生时间却显示已在童限。没有改变本命星曜安置公式，没有根据猜测重写月日时运限，也没有为复刻旧行为撤回既有换日修正。

### 同钟表输入与公开 Demo 的区别

开源 Demo 的表单只加经度差，不计算均时差或校正后的跨日；旧分享转换又独立按钟表23点进日。它自身的两个入口并不完全一致。本地表单和分享统一使用完整真太阳时工具。因此以下差异不应为追求逐字复制而回退：

| 合成输入（女命） | 旧公开 Demo / 分享 | 当前本地 |
|---|---|---|
| 2000-02-11 01:05，杭州120.155° | 丑时，命宫丑 | 含约−14.18分钟均时差后为子时，命宫寅 |
| 1996-06-18 00:15，乌鲁木齐87.616° | 仍用18日亥时 | 校正为17日亥时 |
| 1996-06-18 22:50，黑河127.5° | 仍用18日子时 | 真太阳时约23:19，归19日子时 |
| 1996-06-18 23:05，乌鲁木齐 | Demo保持18日；旧分享错误进19日 | 真太阳时约20:54为戌时，保持18日 |

上述仅比较公开 Demo，不把它的输入行为冒充官网商业版本的全部设置。可复现命令 `npm run audit:metis-natal -- --details`。

## 本轮错误与修复

### 节气四柱丢失分钟

2004-02-04 19:30，关闭真太阳时：旧代码把戌时直接取20:00，显示甲申／丙寅，实际输入尚在立春前，应为癸未／乙丑。2017-02-03 23:20还会遇到晚子归次日后提前跨立春的问题。

修复：归一化输入保留扣除可选夏令时后的东八区 `standardTime`，在真太阳时和晚子换日前保存真实标准时刻。节气年/月柱据此判断；紫微本命、日柱和时柱仍按已经校正的排盘日/时支计算。旧 `BirthInfo` 若没有标准时分，保留时辰中点估算并增加 `fourPillarsTimeSource=branch-midpoint` 来源标记；原始表单档案重新打开后可恢复分钟。

独立交节证据：[日本国立天文台2004表](https://eco.mtk.nao.ac.jp/koyomi/yoko/2004/rekiyou042.html)列2月4日20:56，[2017表](https://eco.mtk.nao.ac.jp/koyomi/yoko/2017/rekiyou172.html)列2月4日00:34。结合其[UTC+9中央标准时说明](https://eco.mtk.nao.ac.jp/koyomi/faq/time.html)，换算东八区分别为19:56和前日23:34。回归测边界两侧，不声称秒级天文精度。

### AI 重建丢失标准时刻

模型提示词会序列化服务端重建后的整张命盘。若忽略新标准时刻，刚修正的节气年/月柱又退回中点，导致网页和AI事实不同。

修复：服务端只接收经过整数、真实日期、东八区、DST标记及合理±1日偏移校验的标准时刻白名单；仍重算星曜，不接受客户端星曜、姓名或地点。新增模拟模型请求检查，确认实际提示词保留正确四柱。没有调用真实模型。

### 同年尚未出生被误标童限

例如北京时间2026-10-17查看出生于2026-12-31的合成盘，单用农历年差得到1岁，误称童限。

修复：已知标准时刻时先比较真实出生瞬间；缺标准时刻的旧记录比较规范化日期/时支。支持同日尚未到出生分钟、晚子归日和真太阳时落前一日的情况。未来盘仍可预览，但“当前大限”明确显示尚未出生。

## 仍需保持的边界

- 上述通过声明是软件规则与所选参考的一致性，不是零缺陷保证或命理命中率证明。
- 非默认出生闰月策略不在本轮完整一致性声明内；先前发现的 `origin-month` 部分闰月三十上游适配错误仍不对网页开放。
- 夏令时日期表沿用参考项目/文墨口径，默认不扣减；原测试已明确1988年起始日与IANA记录有分歧。本轮没有独立裁定所有历史夏令时日期，不能把“与参考一致”写成“已核实全部历史事实”。
- 纯真太阳时模型沿用项目既有均时差近似，当前输入按东八区钟表时间处理，不是全球历史时区转换器。
- 未推送或合并GitHub。本地生产预览已重启加载本轮构建；公开PR仍是此前版本。
