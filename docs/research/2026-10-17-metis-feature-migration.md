# Metis 功能研究与千星已现风格迁移

核查日期：2026-10-17。范围是用户指定的 Metis 功能与千星已现视觉风格，在现有紫微项目中实现可运行的本地应用。本文区分公开页面观察、现有开源能力与本轮实际实现，不把商业版宣传量级写成本地能力。

## 1. 来源与访问范围

- 功能来源：[Metis 首页](https://metisziwei.com/)、[排盘](https://metisziwei.com/chart)、[合盘](https://metisziwei.com/heming)、[命理学双子](https://metisziwei.com/twins)、[三纪](https://metisziwei.com/sanjige)、[学术中心](https://metisziwei.com/academy)。本次读取了这些公开页面，并由主任务在浏览器观察可见入口与交互。
- 风格来源：[千星已现](https://qianxingyixian.com/)。主任务通过 Chrome 现有会话实际打开了用户指定的 `/archives/…/report/…#report-data` 报告，观察到标题与资料区、关于你、目录、折叠技术数据、追问布局。私人正文没有复制，没有保存报告截图或个人资料值。用户已授权先使用公开风格，因此主要保存证据与资源来自公开首页；报告观察仅用于理解组织与交互。
- 实现基础：本项目 `README.md`、`lib/ziwei/`、`lib/classics/`、`lib/seo/` 及 `docs/tianji-ziwei/`。
- 克隆流程：`tools/ai-website-cloner-template`，提交 `ee3f5a2f31fd549b9593fa4f7cf6d2955ee593bb`。复用它的映射、观察、构建、同视口对比流程。详见 `2026-10-17-cloner-workflow.md`。

## 2. Metis 的产品结构

公开首页有五个主要入口：紫微命盘、合盘分析、命理学双子、三纪、学术中心；另有支持、更新、专业版、隐私与条款等辅助入口。页面提供登录状态、普通版/专业版、语言与设置入口。这些是观察到的产品结构，不代表已获得其后端实现。[来源：首页](https://metisziwei.com/)

### 排盘与档案

排盘页提供姓名、公历/农历、日期、北京时间、未知时辰、出生地点和性别。地点用于真太阳时校正；页面还说明登录可保存并跨设备查看记录。本次访问中出现登录后继续的界面，登录后的完整命盘操作和商业 AI 结果没有完成实测。公开表单和登录入口不能证明能从网页恢复会员、数据库与私有断语。[来源：排盘页](https://metisziwei.com/chart)

### 合盘

线上提供感情、合伙、上下级、朋友四种关系入口、两套出生表单，以及 AI 深度解读按钮。页面说明登录后可保存报告并跨设备查看。这里观察到的是输入、功能入口与说明；未验证已登录后的完整报告、保存同步或持续追问体验。[来源：合盘页](https://metisziwei.com/heming)

### 命理学双子

线上定义同盘条件为排盘日、真太阳时辰和性别一致，并展示三类能力：全国同盘人数的统计估算、各地同盘出生时间窗换算、海量配置的结构相似检索。页面自述检索库含 67.5 万独立命盘、13 个解读维度、877 万条文案，覆盖 1950–2026 共 77 年；这些是站方展示的数据规模，本次未下载或验证其数据库。页面同时明确：估算人数与配置数不是真人记录，真人地理分布仍在筹备。[来源：双子页](https://metisziwei.com/twins)

### 三纪与学术中心

三纪是天地人课程组织与精确到秒的原话回放。公开页面展示天纪 **11 部、4886 条、112 单元**，人纪 **6 部、19294 条、117 集**；地纪为三部未竟，分别列出 **6 / 7 / 5 章**。页面称天纪、人纪两库在 GitHub 开源并使用 CC BY-NC-SA。本轮已经从其公开仓库固定提交导入两库结构化数据、README 与许可，验证实际条数、课程数、分类数及文件哈希；这不代表逐条核对全部原视频。地纪原文尚未导入。[来源：三纪页](https://metisziwei.com/sanjige)、[天纪公开库](https://github.com/Renhuai123/nihai-tianji-corpus)、[人纪公开库](https://github.com/Renhuai123/nihai-renji-corpus)

学术中心把学习路径与查证资料分开：第一次学习、继续课程、研究查证；按星曜、双星、格局和古籍进入。页面展示 **182 项星曜专题、24 组双星、37 种格局、6 部古籍、2532 段精华**。其中 182 来自页面标注的 14 主星 × 13 主题结构；这些线上数量不等于本地开放资料量。[来源：学术中心](https://metisziwei.com/academy)

## 4. 风格简报

观察到的千星已现公开首页由轻量页头、留白主视觉、字符构成的行星与环、中文展示字体、短说明和紫色主按钮组成。采用白色背景、近黑文字、淡灰分隔与低装饰密度。报告页另外提供分区目录、技术数据展开与继续追问的阅读结构。此次迁移借用这一视觉语言与内容分层，页面文案和功能组织仍服务于紫微产品。

源 CSS 中核验的基础值：页面背景 `#fff`，品牌色 `#5a5ad6`，按钮近黑色 `#0f0f0f`，正文体 Moonless PuHuiTi，展示体 Moonless Sugar，等宽体 JetBrains Mono。源样式按视口改变展示字号（40 / 56 px）、一级标题（28 / 36 px）和引言（17 / 19 px）；本地在这些风格基础上为多功能页面补充响应式布局，不宣称所有结构尺寸逐像素一致。

本地设计落点：

- `app/studio.css`：颜色、字体、页头、页脚、按钮、首页排版与断点。
- `components/OrbitalField.tsx`：可编辑 Canvas 字符行星，由时间驱动；减少动画时静止但跟随主题和尺寸重绘；页面隐藏或离开可视区域时暂停。
- `components/ChartWorkspace.css`：排盘表单、命盘工作台与档案。
- `components/ExplorePages.css`：合盘、样本比较、学堂、知识与阅读页。
- `components/InsightPanel.tsx`：白底/深色主题、紫色强调的真实 AI 对话。

## 5. AI 行为与验证界限

`/api/interpret` 和 `/api/heming` 支持 OpenAI 兼容协议与 Anthropic Messages。密钥仅服务端读取，型号由用户配置。服务器校验请求、从规范出生输入重建命盘，不信任客户端星曜字符串；输入体量、对话长度、输出和请求时间都有边界。流传输支持取消与跨 chunk 的中文字符；错误脱敏，不回传上游正文、密钥或堆栈。

未配置时返回 `503 AI_NOT_CONFIGURED` 和可理解的说明，不返回伪造的报告。AI 为主动点击后才执行，不在打开命盘时自动产生模型调用。当前已用合成输入和模拟上游验证两种协议与路由、追问、SSE 拆包、输入错误、取消、超时与错误显示；**没有使用真实密钥实测模型服务**。传输测试通过不意味着模型内容已获准确性验证。详情在 `lib/ai/README.md`。

## 7. 检查与继续验收

本轮 AI 独立检查已通过 `node node_modules/tsx/dist/cli.mjs lib/ai/api.test.ts` 和当时的全项目 `npm run typecheck`。两库回归 `node node_modules/tsx/dist/cli.mjs scripts/regression/reference-corpora.test.ts` 验证固定哈希、24180条、229独立课程、检索筛选、分页及精确回放链接；已通过。主任务负责最终集成的排盘回归、生产构建、浏览器真实工作流以及桌面/移动端视觉比较；最终检查结果应按实际运行记录追加，不以本文件替代完成证明。

需要保留的浏览器验收场景：示例起盘、有效/无效日期、农历与晚子时、宫位选择、运限切换、档案保存/重开/删除、导出、合盘两表单与新问题、双子过滤、知识跳转、古籍搜索与段落锚点、课程查询与翻页、无 AI 配置提示、主题切换、移动菜单与横向溢出。

最终集成结果：`npm test` 12组通过、`npm run typecheck`通过、最终`npm run build`通过，57个静态页面及相关动态路由生成成功。生产模式的首页、排盘、合盘、双子、学术中心、人纪检索、导读检索均HTTP 200。实际浏览器已核对示例盘、键盘选宫、2027流年、合成档案保存刷新、双人计算与关系切换、8城市同盘时间窗、导读搜索、跨库分类检索、主题与手机菜单；真实模型、档案删除和下载完成不属于已验证UI结果。详情见根目录 `design-qa.md`。
